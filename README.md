# 🧠 TODO App (Minimal Productivity System)

A clean, minimal, and modern productivity app built with **Next.js + TypeScript + Tailwind CSS**.

> Focus on simplicity. No clutter. Just action.

---

## ✨ Features

### 📝 Tasks
- Add / delete tasks
- Mark as completed
- Clean minimal UI
- Local storage support

### 🔁 Habits
- Add daily habits
- Mark completion
- Simple tracking system

### 📅 Calendar
- Select date
- Highlight current day
- Clean visual feedback

### 👤 Profile
- App settings UI
- Feature sections (customize, widgets, etc.)
- App info & version display

### 🧭 Navigation
- Floating navbar (Apple-style)
- Smooth interactions
- Dynamic tab switching

---

## 🎯 Tech Stack

- **Frontend:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Storage:** LocalStorage
